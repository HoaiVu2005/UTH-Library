# Design System & UI/UX Context: UTH Library Management System

## Design Context

### Users
- **Primary Users (Patrons):**
  - **Students (Sinh viên):** Need fast, self-service book lookup, syllabus tracking, real-time availability check, 1-click book renewal, reservations queue tracking, fine payment guidance, and book purchase recommendations. Context: Frequent mobile/laptop browsing between lectures, seeking immediate clarity without cognitive clutter.
  - **Lecturers / Faculty (Giảng viên):** Need elevated loan limits (up to 10 books, 30 days) and academic reference tracking for course syllabus preparation.
- **Secondary Users / Operators (Library Staff & Administrators):**
  - **Circulation Librarians (Thủ thư quầy lưu thông):** Barcode scanner-driven workflow at the circulation desk (`CirculationDeskPage`), rapid cart-based checkout, instant return processing with physical book condition appraisal (normal, damaged, lost), fine collection, and hold queue management.
  - **System Administrators (Quản trị viên):** Catalog management (books & copies with Code128 barcoding), user lifecycle management (extend card, lock/unlock, password reset), fine management (waiving with mandatory justification), audit logging, and circulation policy rules.

### Brand Personality
- **Voice & Tone:** Professional, Academic, Modern, Trustworthy, Disciplined ("Chuyên nghiệp, Hiện đại, Tin cậy, Thân thiện").
- **3-Word Personality:** **Authoritative, Crisp, Accessible.**
- **Emotional Goals:** Instill confidence, provide calm visual clarity, eliminate ambiguity around loan due dates/penalties, and deliver frictionless speed for daily university operations.

### Aesthetic Direction
- **Visual Direction:** Modern Enterprise Dashboard meets Clean University Portal. Card-based information architecture inspired by the official UTH Student Portal, upgraded with modern typography, subtle micro-interactions, and balanced whitespace.
- **Color Palette:**
  - **Primary Brand (Teal):** `#008B8B` (Default), `#006F70` (Dark/Hover), `#E6F4F3` (Soft tint/Background highlight).
  - **Accent & Secondary (Orange):** `#ED6C02` / `#FF6600` for critical badges, urgent alerts, and high-visibility notifications.
  - **Backgrounds:** `#F3F6F8` (Page canvas), `#FFFFFF` (Surface cards), `#F8FAFC` (Table alternating rows).
  - **Typography & Ink:** `#263238` (Text Primary), `#64748B` (Text Secondary/Muted).
  - **Borders & Dividers:** `#E2E8F0` (Thin, delicate borders).
  - **Semantics:** `#16A34A` (Success), `#F59E0B` (Warning), `#EF4444` (Danger), `#3B82F6` (Info).
- **Typography Stack:** `"Be Vietnam Pro"`, `"Inter"`, system-ui, sans-serif. Strict hierarchy with deliberate font-weight distinctions (avoiding excessive bolding).
- **Anti-References:**
  - Avoid generic AI templates or sterile dark-mode crypto aesthetics.
  - Avoid gratuitous multi-color gradients, neon accents, or low-contrast text.
  - Avoid information dumping: no cluttered card stacks, no redundant nested borders, and no oversized empty voids.

### Implementation Defaults
- **Runtime & Framework:** React 18 (`18.3.1`) + TypeScript (`5.6.3`) + Vite (`5.4.8`) SPA.
- **Styling System:** Tailwind CSS (`3.4.13`) configured with Master Design System tokens (`primary`, `brand`, `pageBg`, `surface`, `textPrimary`, `textSecondary`, `border`).
- **Component Architecture:** In-house component system located at `frontend/src/components/ui/` (`Button`, `Badge`, `Input`, `StatCard`, `CalendarMonth`, `ConfirmDialog`, `EmptyState`, `ErrorState`, `Skeleton`, `Pagination`).
- **Form Architecture:** React Hook Form (`7.53.0`) + `@hookform/resolvers` + `zod` (`3.23.8`) alongside standard controlled form state for agile dialogs.
- **Table / Data-Grid Architecture:** Custom responsive semantic HTML tables with sticky headers (`bg-gray-50/80`), row hover interactions (`hover:bg-teal-50/30`), status badge mappings, and unified action icon buttons.
- **Data Fetching & State:** `@tanstack/react-query` (`5.59.0`) + Axios (`1.7.7`) + `AuthContext` (JWT rotation with silent refresh).
- **Data Visualization:** Recharts (`2.13.0`) for circulation analytics and trends.
- **Iconography:** Lucide React (`lucide-react@0.453.0`) with consistent 16px/18px/20px strokes.
- **Precedence Order:**
  1. Existing project stack & customized design tokens (detected from `frontend/`).
  2. UTH Student Portal visual identity and layout patterns.
  3. Master Design System specifications.

### Design Principles
1. **Usability and Visual Clarity First ("Less is More"):**
   Every screen has one unambiguous primary objective. Prioritize information hierarchy with disciplined spacing, card separation, and typography weight before applying color. Never overwhelm the user with repetitive cards or nested containers.
2. **Authentic UTH Identity with Refined Modernity:**
   Anchor the portal in UTH Teal (`#008B8B`) with restrained Orange (`#ED6C02`) for urgent signals. Retain recognizable university portal patterns (e.g. structured 2-column student info with 125x165 portrait, interactive monthly calendar with teal ring on the current day, 8 function quick-access grid) while eliminating outdated design flaws.
3. **Strict Vertical Alignment and Controlled Geometry:**
   Tabular data, metadata lists, and form fields must align with exact label baselines and fixed label widths (`w-20`, `w-28`). Maintain uniform card border radiuses (12px–16px), balanced inner padding (16px–24px), and eliminate asymmetric whitespace voids.
4. **Resilient Feedback & State Transparency:**
   Every user action triggers immediate, predictable visual feedback: loading skeletons during data fetches, zero-layout-shift empty states with clear calls-to-action, inline validation alerts, and non-destructive confirmation dialogs for critical transactions (loan renewals, reservations cancellation, card locking).
5. **Desk Speed & Barcode Readiness:**
   Circulation workflows must support keyboard-first barcode scanner inputs (auto-focus, `Enter` submission) and cart checkout models without unnecessary modal interruptions or mouse dependencies.
